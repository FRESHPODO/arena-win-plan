# League of Legends Arena image assets

This directory is generated by `scripts/download-assets.ps1`.

- `champions/icons`: current square champion portraits
- `champions/splash`: current base-skin splash art
- `augments/icons`: Arena augment large icons
- `items/legendary`: current Summoner's Rift legendary item icons used as the canonical art
- `items/prismatic`: Arena prismatic item icons
- `items/anvil`: Arena stat, class legendary, and prismatic anvil icons
- `items/exclusive`: purchasable Arena-only item icons that have no same-named Summoner's Rift item

Every section contains `manifest.json` and `manifest.csv`. Each manifest records the
game ID, display name, local path, source URL, and (where applicable) patch version.
Item and augment manifests use Korean `name` / `nameKo` and preserve English in
`nameEn`. Run `scripts/localize-assets.ps1` to refresh names without downloading
images. Localization sources and the update timestamp are in `localization.json`.
`sources.json` records the upstream data endpoints and generated counts.

The images are Riot Games assets. Their use is subject to Riot Games' legal terms.
CommunityDragon is used as an unofficial mirror of files shipped in the game client.

To refresh the assets from the current live patch:

```powershell
pwsh -File .\scripts\download-assets.ps1
```
