# 아레나농가

리그 오브 레전드 아레나 모드의 추천 빌드를 모아 보는 팬 사이트입니다.

## 사이트 바로가기

### [아레나 추천 빌드 정리 열기](https://freshpodo.github.io/arena-win-plan/)

## 주요 기능

- 추천 빌드를 최근 등록순으로 둘러볼 수 있습니다.
- 빌드 이름, 설명, 아이템, 증강 키워드로 검색할 수 있습니다.
- 추천 챔피언을 기준으로 빌드를 찾을 수 있습니다.
- 각 빌드의 핵심 아이템, 증강, 추천 챔피언과 설명을 확인할 수 있습니다.
- 도감에서 아레나 아이템과 증강을 등급별로 살펴볼 수 있습니다.
- 원하는 조합을 직접 작성하고 이미지 또는 JSON 파일로 저장할 수 있습니다.
- 빌드 상세 주소를 그대로 복사해 다른 사람에게 공유할 수 있습니다.

## 이용 안내

상단의 **추천 빌드 정리**에서 공개된 빌드를 확인하거나 **도감**에서 아이템과 증강을 검색하세요. 새로운 조합은 **빌드 작성**에서 만들 수 있습니다.

빌드 작성 화면에서 저장한 JSON 파일은 개인 보관용입니다. 사이트에 새 빌드로 게시하려면 저장소 관리자가 해당 파일을 검토한 뒤 반영해야 합니다.

## 참고 사항

- 이 프로젝트는 Riot Games와 무관한 비공식 팬 프로젝트입니다.
- 게임 패치에 따라 실제 아이템, 증강 및 수치가 사이트의 데이터와 달라질 수 있습니다.
- 첫 번째 빌드는 제공된 콘셉트를 옮긴 예시이며 최신 게임 효과를 별도로 검증한 공략이 아닙니다.
- 이미지와 데이터 출처는 [`imgs/README.md`](imgs/README.md)와 관련 데이터 파일에 기록되어 있습니다.
- 일부 위키 기반 데이터는 원문의 라이선스 조건에 따라 제공됩니다.

## 프로젝트 관리

빌드 추가와 저장소 관리 절차는 [`BUILD_MANAGEMENT.md`](BUILD_MANAGEMENT.md)를 참고하세요.
