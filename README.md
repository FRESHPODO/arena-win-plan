# 아레나농가

리그 오브 레전드 아레나 모드의 추천 빌드를 모아 보는 사이트입니다.

## 사이트 바로가기

### [아레나 추천 빌드 정리 열기](https://freshpodo.github.io/arena-win-plan/)

## 주요 기능

- 추천 빌드를 최근 등록순으로 둘러볼 수 있습니다.
- 빌드 이름, 설명, 아이템, 증강 키워드로 검색할 수 있습니다.
- 추천 챔피언을 기준으로 빌드를 찾을 수 있습니다.
- 각 빌드의 핵심 아이템, 증강, 추천 챔피언과 설명을 확인할 수 있습니다.
- 도감에서 아레나 아이템과 증강을 등급별로 살펴볼 수 있습니다.
- 원하는 조합을 직접 작성하고 이미지 또는 JSON 파일로 저장할 수 있습니다.
- 빌드 상세 주소를 그대로 복사해 다른 사람에게 공유할 수 있습니다.
- `overlay.html`에서 최대 6개의 활성 증강과 레벨을 설정하고, 등급별 색상으로 표시한 투명 PNG를 저장할 수 있습니다. 열 수, 전체 폭, 아이콘·글자 크기, 간격, 여백, 배경 불투명도를 조절할 수 있습니다.

## 이용 안내

상단의 **추천 빌드 정리**에서 공개된 빌드를 확인하거나 **도감**에서 아이템과 증강을 검색하세요. 새로운 조합은 **빌드 작성**에서 만들 수 있습니다.

빌드 작성 화면에서 저장한 JSON 파일은 개인 보관용입니다. 사이트에 새 빌드로 게시하려면 저장소 관리자가 해당 파일을 검토한 뒤 반영해야 합니다.

## OBS 실시간 오버레이

`npm start`로 로컬 서버를 실행하고 `http://127.0.0.1:4173/overlay-realtime.html`에서 증강을 설정하세요. OBS 브라우저 소스 URL에 `http://127.0.0.1:4173/overlay-live.html`을 입력하고 소스 크기를 1920 × 1080으로 설정하면 편집 화면의 변경 사항이 자동 반영됩니다. 전체 폭을 더 크게 설정하면 OBS 소스 폭도 늘려 주세요. 출력 페이지는 투명 배경이며 활성 슬롯이 없으면 아무것도 표시하지 않습니다. 같은 PC에서 서버를 실행한 상태로 사용해야 하며, 게임 상태를 자동으로 인식하지는 않습니다. 서버가 재시작되면 열린 편집 화면에서 5초 이내에 다시 연결합니다. GitHub Pages에서는 PNG 기능을 사용할 수 있고 실시간 연결은 로컬 서버가 필요합니다.

## 참고 사항

- 이 프로젝트는 Riot Games와 무관한 비공식 팬 프로젝트입니다.
- 게임 패치에 따라 실제 아이템, 증강 및 수치가 사이트의 데이터와 달라질 수 있습니다.
- 첫 번째 빌드는 제공된 콘셉트를 옮긴 예시이며 최신 게임 효과를 별도로 검증한 공략이 아닙니다.
- 이미지와 데이터 출처는 [`imgs/README.md`](imgs/README.md)와 관련 데이터 파일에 기록되어 있습니다.
- 일부 위키 기반 데이터는 원문의 라이선스 조건에 따라 제공됩니다.

## 프로젝트 관리

## 라운드별 투명 영상 소스

오버레이 편집 화면 아래에 라운드 시작 시간을 한 줄씩 입력하고, 각 라운드를 불러와 증강을 수정한 다음 **현재 상태 저장**을 누릅니다. 영상 종료 시간, 프레임률, 고정 소스 크기를 입력한 뒤 Premiere Pro 또는 Final Cut Pro를 선택하고 **투명 MOV 영상 생성**을 누르세요. 기본은 알파 채널을 포함한 Animation MOV이며, ProRes 4444 MOV도 선택할 수 있습니다. 원본 영상 위 트랙에 00:00부터 배치하면 시간별 증강이 표시됩니다. 위치는 편집 프로그램에서 조절합니다. 첫 시작 전은 투명하고 마지막 라운드는 영상 종료까지 유지됩니다.

생성 중에는 로컬 서버와 편집 화면을 열어 두세요. 생성 파일은 `exports/`에 저장됩니다. FFmpeg는 `tools/ffmpeg/ffmpeg.exe`, 환경 변수 `FFMPEG_PATH`, 또는 PATH에 있는 `ffmpeg` 순으로 사용합니다. 새 환경에서는 FFmpeg를 설치하고 경로를 지정해야 합니다. Animation MOV는 정지 구간의 반복 데이터를 줄입니다. ProRes는 편집 표준 옵션으로 유지합니다. 원본 영상과 같은 정수 프레임률(24/30/60fps)을 사용하세요.

빌드 추가와 저장소 관리 절차는 [`BUILD_MANAGEMENT.md`](BUILD_MANAGEMENT.md)를 참고하세요.
라운드 변경 강조를 켜면 추가는 초록 테두리, 레벨업은 금색 테두리, 제거는 분홍색 알림으로 표시됩니다. 강조 시간은 0.1~3초로 설정할 수 있으며 짧은 라운드는 해당 라운드 길이로 제한됩니다. 강조는 영상에 직접 포함되며 전환 시점과 전체 길이는 유지됩니다.
증강 출력 크기는 6칸 전체를 기준으로 고정됩니다. 실제 증강 개수가 바뀌어도 전체 이미지 크기와 카드 크기는 유지되며 빈 영역은 투명하게 남습니다.

## 편집용 모루 오버레이

편집용 오버레이 아래의 **모루 표시**에서 사용합니다. 왼쪽에서 ROFL 파일을 선택하고 대상 플레이어 인덱스(0부터) 또는 정확한 Riot ID를 입력한 뒤 **선택한 ROFL에서 모루 추출**을 누르세요. 라운드가 없으면 시간을 먼저 자동 추출합니다. `arena_rofl_core/parse_anvils.cjs` 결과 JSON도 불러올 수 있습니다. 포함된 코어는 16.19.823.0722를 지원합니다.

각 스탯은 아이콘, 이전 라운드의 총합, 이번 라운드 합계, 잠시 나타나는 현재 모루 수치 순으로 표시합니다. 현재 수치는 1.2초 뒤 라운드 합계에 합쳐지고, 전투 전환 시 라운드 합계가 총합으로 이동하며 강조됩니다. 미리보기 시각과 **효과 재생**으로 확인하세요. **현재 모루**를 선택하면 해당 시각으로 이동합니다. 지정 구간 합계는 시작·종료 시각을 모두 포함합니다.

라운드를 선택하여 파편검 증폭률을 퍼센트로 입력하세요(40 입력 = 기본 수치의 1.4배). **이후 라운드에도 같은 값 적용**은 이후 라운드의 증폭률을 덮어씁니다. 각 모루는 해당 라운드의 증폭률로 계산합니다. 근접·원거리 조건을 선택할 수 있고, 변신 등으로 개별 보정이 필요하면 현재 모루 기본 스탯 JSON을 입력합니다. 비스탯 파편은 스탯 합계에 추가하지 않습니다. 유료 구매 여부는 아직 확인되지 않아 무료 지급도 포함하며, 필요한 알림은 제외할 수 있습니다. 게임의 다른 스탯 배율·비선형 중첩 효과는 계산하지 않습니다.

**모루 투명 PNG 저장**은 현재 시각을, **모루 투명 MOV 생성**은 영상 시간 및 출력 설정의 종료 시각·프레임률을 사용합니다. MOV에는 등장·이동·합산 강조 효과가 포함됩니다. 증강 MOV와 별도 파일이므로 편집 프로그램에서 독립적으로 배치할 수 있습니다. 원본 영상 위에 00:00부터 올리세요. 모루가 있는 라운드의 전투 전환 시간은 모두 입력해야 합니다. 데이터와 보정값은 현재 브라우저에 저장됩니다.

## 로컬 임시 파일과 사용자 설정

- 서버가 포트 4173에 연결된 뒤 `.runtime-cache/`의 이전 리플레이 임시 파일을 초기화합니다. 중단된 영상 작업의 UUID 폴더와 PNG·분할 MOV 중간 파일도 정리합니다. 기존 완성 MOV와 직접 저장한 파일은 시작 정리에서 보존합니다. 현재 실행에서 생성한 영상은 기존처럼 다운로드 완료 또는 만료 후 정리됩니다.
- 설정·레이아웃의 브라우저 저장값은 정리 대상이 아닙니다. `user_custom/`와 임시 캐시는 `.gitignore`로 제외하므로 일반 Git 업데이트가 개인 설정을 덮어쓰지 않습니다. `git clean -x`처럼 무시 파일까지 삭제하는 명령은 별도입니다.
- 영상 생성 및 리플레이 요청은 한 번에 하나만 받습니다. 정적 파일은 스트리밍하고, 인코딩이 끝난 구간의 PNG 데이터는 참조를 해제합니다.
- `exports/replay-round1`, `exports/replay-object-timelines`, `exports/replay-player-candidates`는 연구용 중간 산출물이며 실행에 필요하지 않아 제거했습니다. 재추출 스크립트와 원본 데이터·코어·Node·FFmpeg는 보존했습니다.
- 검증: `tools/node/node.exe scripts/check.cjs`, `tools/node/node.exe scripts/test-anvils.cjs`, `tools/node/node.exe scripts/test-runtime-cleanup.cjs`.
